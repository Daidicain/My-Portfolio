Backstock Tracker App

2022

Designed and developed an inventory management application used to support daily backstock operations. The application consolidated several inventory management processes into a single interface, improving workflow efficiency, reducing data-entry errors, and providing greater visibility into inventory forecasting and replenishment activities.

Project Objectives:

  • Improve inventory data accuracy and consistency
  • Reduce manual effort and repetitive tasks
  • Streamline inventory and replenishment workflows
  • Provide greater visibility into forecast and stock changes
  • Create a centralized tool for backstock management
Article Lookup

Search for an item and view detailed inventory information, including replenishment settings, forecast values, and product metadata from the database.

Article Overide

Modify key inventory parameters such as Shelf Replenishment Quantity (SRQ) and case size. These adjustments directly influence replenishment calculations and stocking recommendations throughout the system.

Forecast Menu

Displays all forecast adjustment requests in a centralized view, allowing users to easily track, review, and manage pending inventory forecast changes.

Forecast Details

Provides a detailed breakdown of a selected forecast request, including requested changes, supporting information, and approval status.

Forecast Form

Allows users to submit new forecast adjustment requests through a structured form, helping standardize inventory planning and reduce data-entry errors.

Reversepick Menu

Generates replenishment recommendations by identifying items that should be moved from backstock to the sales floor. Quantities are clearly distinguished between individual units and full cases, and storage locations are displayed to speed up item retrieval.

Car Rental Inventory Software

2022

Developed a full-stack car rental management application to demonstrate database design principles and business application development. The project began with designing a normalized relational database schema to model customers, vehicles, and rental transactions, followed by the implementation of an inventory management, rental tracking, authentication, and reporting system.

Technologies & Skills:

  • Relational database design and normalization
  • Entity relationship modeling
  • CRUD application development
  • User authentication and access control
  • Inventory management systems
  • Reporting and data analytics
User Authentication

Secure login interface used to authenticate users and restrict access to authorized personnel before accessing rental and inventory data.

Vehicle Inventory Management

Displays the company's vehicle fleet and associated information. Users can search, filter, add, update, and remove vehicles while maintaining accurate inventory records within the database.

Rental Management

Tracks active and historical vehicle rentals. Users can create new rental agreements, manage existing rentals, and process returns through a centralized interface.

Inventory Reporting

Generates real-time reports using data from the vehicle inventory database, providing insight into fleet availability, utilization, and overall inventory status.
